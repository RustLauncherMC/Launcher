What it is

Two editions.
One window.

Horizon and Cinnabar each ship their own launcher. RustLauncherMC puts them side by side, the way the official launcher puts Java and Bedrock side by side, and does the work each game expects from its launcher.

Java Edition

through Horizon

  • Signs you in with Microsoft and checks that you own Java Edition.
  • Installs the newest Horizon nightly, checked against Horizon's signed checksums.
  • Prepares Horizon's game files from your own copy of Minecraft 26.3, getting Java 25 if you need it.
  • Starts the game with your account, so you can join online-mode servers.

Bedrock Edition

through Cinnabar

  • Installs Cinnabar's official Beta or Nightly release, checked against its SHA-256 sums.
  • Finds a copy you already installed with Cinnabar's own installer.
  • Starts the game, which handles its own sign-in, account switching and the Minecraft EULA.
  • Lets Cinnabar keep itself up to date, as it's designed to.

How it works

From download
to playing.

  1. 1

    Install the launcher

    The Windows installer needs no administrator approval. On Linux, use the AppImage, the .deb, or the plain binary.

  2. 2

    Pick an edition

    For Java, sign in with a Microsoft account that owns Java Edition. For Bedrock, Cinnabar signs you in inside the game.

  3. 3

    Press Play

    The first start downloads the game and gets its files ready. After that, Play starts it straight away.

FAQ

Questions.

Is this an official Minecraft launcher?

No. RustLauncherMC is a fan project. It isn't affiliated with Mojang or Microsoft, or with the Horizon or Cinnabar projects. It contains no Minecraft code, assets or data.

Do I need to own Minecraft?

For Java Edition, yes: Horizon is prepared from your own copy of Minecraft: Java Edition 26.3, and the launcher only starts it for a Microsoft account that owns the game. For Bedrock Edition, Cinnabar asks you to accept the Minecraft EULA and signs you in with your Microsoft account.

Why does Java sign-in say the app isn't approved?

Minecraft only lets apps that Mojang has approved sign players in. RustLauncherMC's sign-in app is waiting for that approval. Until then, Bedrock works as normal.

Is there a macOS version?

Not for now. The launcher is made for Windows and Linux.

Can servers ban me?

Cinnabar's own README warns that its movement and combat may not match the official client yet, so some servers' anticheats may flag it. Play on servers at your own risk.

Does it cost anything?

No. RustLauncherMC is free and stays noncommercial, also because Cinnabar's licence (PolyForm Noncommercial) doesn't allow commercial use.
